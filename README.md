## Gozara

### Meaning of the name
Gozara / `گذرا` is a Persian word meaning ephemeral. It's romanized as Gozara and is pronounced `gɜːzæra`.

### Overview
It's a p2p ephemeral(up to one hour) blob storage and communication network tailored to Ethereum L1 block proving. The goal is to provide a decentralized storage solution similar to Amazon S3.
